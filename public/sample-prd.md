# 상품 목록 관리 화면 PRD

## 개요
OCMP 어드민에서 판매 상품을 검색하고 상태를 관리하는 화면이다.

## 화면 목록
1. 상품 목록 화면 — 검색 조건으로 필터링하여 결과 테이블 표시
2. 상품 상세 모달 — 목록에서 행 클릭 시 상세 정보 확인

## 기능 명세

### 1. 상품 목록 화면

#### 검색 조건
- 상품명 (텍스트 입력)
- 브랜드명 (텍스트 입력)
- 판매 상태 선택: 판매중 / 판매중지 / 품절

#### 검색 결과 테이블
| 컬럼 | 설명 |
|------|------|
| 상품ID | 고유 식별자 |
| 상품명 | 상품 이름 |
| 브랜드 | 브랜드명 |
| 판매가 | 판매 금액 (원 단위) |
| 판매 상태 | 판매중 / 판매중지 / 품절 |

#### 행 동작
- 행 클릭 시 상품 상세 모달 오픈

#### 액션
- 검색 버튼: 조건 적용하여 목록 재조회
- 초기화 버튼: 검색 조건 초기화
- 삭제 버튼 (행별): 확인 팝업 후 해당 상품 삭제

### 2. 상품 상세 모달

#### 표시 항목
- 상품ID
- 상품명
- 브랜드
- 판매가
- 판매 상태
- 상품 설명

#### 액션
- 닫기 버튼: 모달 닫기
- 판매중지 버튼: 상태를 판매중지로 변경 (판매중일 때만 표시)
- 판매재개 버튼: 상태를 판매중으로 변경 (판매중지일 때만 표시)

## 상태 정의
- **판매중**: 정상 판매 상태
- **판매중지**: 관리자가 수동으로 판매를 중지한 상태
- **품절**: 재고 소진으로 인한 판매 불가 상태

## 에러 처리
- 검색 실패 시 에러 메시지 표시
- 삭제 실패 시 에러 메시지 표시
